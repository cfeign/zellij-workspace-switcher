# History

Design notes and implementation plans from the original private version of this project, kept because they explain *why* things are the way they are. Dates are in the filenames.

They were written for a specific machine and have been lightly scrubbed. Names changed since they were written:

| In these docs | Now |
|---|---|
| `lazygit-N` pane | `git-N` (command configurable; was a fish shell at the end) |
| `bv-N`, then `iv-N` pane | `issues-N` (command configurable; defaults to a shell) |
| `workspace-minimal.kdl` | `workspace-8.kdl` |
| session `workspace2` | `workspace-8` / `workspace-6` |
| `~/scripts` as the projects folder | `projects_root` in projects.json |
| Hammerspoon, dev-tab, pane-grab, the Megalodon keyboard | removed; they depended on personal hardware and tools |

The "For Claude: use superpowers:executing-plans" headers refer to a Claude Code plugin the author used; ignore them.
