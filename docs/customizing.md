# Customizing

Everything below is a config edit or a one-line script change. Rebuilding the plugin is only needed for things the plugin owns: pane geometry in focus mode, the grid shapes, the pane types themselves.

## Grid size: 6 or 8

Set `"grid": 6` or `8` in `~/.config/zellij/projects.json` and run `generate-layout.sh`. Or pass `--grid 6` to `zellij-workspace start` for a one-off. Both layouts are generated by `setup.sh`, so switching is just a different session name (`workspace-6` vs `workspace-8`). The plugin picks 2x3 or 2x4 by counting slots it sees, so no plugin change is involved.

Other sizes (4, 9, 12) would need new coordinate tables in `generate-layout.sh` and `build_grid_coordinates()` in `src/main.rs`.

## What runs in each pane

`panes` in `projects.json`:

```json
"panes": {
  "claude": "claude-workspace",
  "git": "lazygit",
  "issues": "gh issue list --web",
  "test": "",
  "adhoc": ""
}
```

Empty means the shell from `"shell"`. A bare name is resolved on PATH at generation time and written as an absolute path into the layout, which is also passed to the plugin so live swaps open the same thing. Commands with arguments are not supported in the layout; wrap them in a tiny script and name that instead.

The five pane types are fixed in the plugin. Renaming one (say `issues` to `docs`) means changing `PaneType` in `src/main.rs`, the `panes` key in `generate-layout.sh`, and the quick-focus comment in `config.kdl`. Adding a sixth means also giving it a position in `tool_coords()`.

The Claude pane runs `scripts/claude-workspace`. Edit `ARGS` there to change how Claude Code starts, for example removing `--permission-mode auto`.

## Keybindings

All in `config/config.kdl`, which is symlinked to `~/.config/zellij/config.kdl`. Zellij reloads it on save for most changes; keybinding changes sometimes need a detach and reattach.

Structure:

```kdl
keybinds clear-defaults=true {
    shared_except "locked" {          // active in every mode except locked
        bind "Alt s" { Run "bash" "-c" "$HOME/.local/bin/zellij-swap" { floating true; close_on_exit true } }
        bind "Alt 3" { MessagePlugin "file:~/.config/zellij/plugins/workspace_switcher.wasm" { name "switch"; payload "focus 3" } }
        bind "Alt f" { ToggleFocusFullscreen; }
    }
    locked  { bind "Ctrl g" { SwitchToMode "Normal"; } }
    resize  { bind "h" "Left" { Resize "Increase Left"; } ... }
    normal  { bind "Ctrl n" { NewPane; } }
}
```

- `clear-defaults=true` drops all of Zellij's stock bindings (Ctrl+p pane mode, Ctrl+t tab mode, and so on). Delete that attribute to keep them alongside these.
- Key names: `"Alt x"`, `"Ctrl x"`, `"Alt Shift 1"`, `"F5"`, `"Left"`. Alt is Option on macOS, which needs the terminal setting below.
- Actions reference: https://zellij.dev/documentation/keybindings-possible-actions
- Plugin commands you can bind with `MessagePlugin`: `grid`, `focus N`, `focus-pane claude|git|issues|test|adhoc`, `quick-focus N`, `swap-slot N name path`, `close-slot N`, `rescan`.
- Scripts run via `Run "bash" "-c" "..."` because KDL has no variable expansion; bash expands `$HOME`. Zellij spawns these with a minimal environment, which is why the scripts prepend Homebrew and `~/.local/bin` to PATH themselves.

Swapping the Alt layer for something else: if Alt conflicts with your editor or terminal, change the prefixes. Zellij also supports a leader-key style via modes: bind a key to `SwitchToMode "Tmux"` and put the bindings in a `tmux { }` block.

Lock mode (`Ctrl+g`) is the escape hatch for any TUI that needs the Alt keys itself.

## Zellij settings

Bottom of `config.kdl`:

| Setting | Why it's set this way |
|---|---|
| `pane_frames true` | Frame titles are how you tell slots apart, and the attention highlight is a frame colour. |
| `default_shell "fish"` | Shell for panes you open by hand with Ctrl+n. Independent of `"shell"` in projects.json. |
| `theme "workspace"` with only `frame_highlight` set | Blue highlight for "Claude is waiting". Add a full theme block or use a built-in: `theme "catppuccin-mocha"`. List: https://zellij.dev/documentation/themes |
| `session_serialization false` | The layout is regenerated from projects.json; serialised sessions would fight it. |
| `on_force_close "detach"` | Closing the terminal detaches instead of tearing down 40 processes. |

Other things people change: `mouse_mode false`, `copy_command "pbcopy"`, `scroll_buffer_size 50000`, `default_layout`. Full list: https://zellij.dev/documentation/options

## Focus-mode layout

Claude takes the left half, tools the right half in a 2x2. To change proportions edit `tool_coords()` in `src/main.rs` (percentages of the screen) and the matching tool pane geometry in `generate-layout.sh`, then rebuild. The layout file's coordinates only matter until the plugin's first repositioning, but keeping them in sync avoids a flash.

## Terminal: Ghostty

`config/ghostty/config` has the relevant lines. The one that matters:

```
macos-option-as-alt = true
```

Without it Option+1 types `¡`. Ghostty's own keybinds beat Zellij's; by default none of them use plain Alt+number, Alt+letter, or Alt+Shift+number, so there's no conflict out of the box. If you add Ghostty binds, keep them on Cmd, which never reaches the terminal.

To open straight into the workspace: `command = /opt/homebrew/bin/fish -c "zellij-workspace start"`. Ghostty also has `initial-command` if you want a plain shell on later windows.

Reload Ghostty config with Cmd+Shift+comma.

## Terminal: others

- **iTerm2:** Preferences, Profiles, Keys, set Left Option to "Esc+".
- **Kitty:** `macos_option_as_alt yes` in kitty.conf.
- **WezTerm:** `send_composed_key_when_left_alt_is_pressed = false`.
- **Alacritty:** `option_as_alt = "Both"` under `[window]`.
- **Linux:** Alt works out of the box in every terminal. The scripts' macOS-only bits are the sound picker (`afplay`), the font picker (Ghostty), and `pbcopy`/`open` in `zellij-urlpick`; swap for `paplay`, `wl-copy`/`xclip`, and `xdg-open`.

## Shell

The scripts are bash and don't care what your interactive shell is. `"shell"` in projects.json picks what empty panes run; `default_shell` in config.kdl picks what Ctrl+n opens. Set both to `zsh` or `bash` if you don't use fish.

## Claude Code

- Startup flags: `scripts/claude-workspace`.
- Per-project sounds: `S` in the picker writes a `Stop` hook into the project's `.claude/settings.json` that runs `afplay`. Drop `.mp3` files into `~/.config/claude-sounds/`.
- Attention highlighting: the hooks in the README. The polling interval is `set_timeout(2.0)` in `src/main.rs`.
